# Data dictionary

All shares are percentages (0–100). Income in euros (annual). Generated by the
`R/` pipeline; see `docs/methodology.md`.

## `tierA_commune_panel` — long (one row per commune × year × round × candidate)

| column | type | description |
|--------|------|-------------|
| code_commune | chr | INSEE commune code, harmonized to `geo_ref_year` (5 chars) |
| year | int | election year (1988,1995,2002,2007,2012,2017,2022) |
| round | int | 1 or 2 |
| code_departement | chr | department code (metropolitan only) |
| nom, prenom | chr | candidate surname / first name |
| party | chr | party label (from lookup) |
| family | chr | political family (socialiste, communiste, ecologiste, gauche_radicale_LFI, extreme_gauche, divers_gauche, centre, droite, extreme_droite, souverainiste, divers, non_classe) |
| is_left | int | 1 if counted as Left (from editable lookup) |
| coverage | chr | "full" (2002–2022) or "communes_gt_9000" (1988/1995 CDSP, urban-biased) |
| voix | int | votes for this candidate in this commune/round |
| inscrits, votants, exprimes | int | registered / turnout / valid votes (commune total) |
| share | dbl | 100 × voix / exprimes |
| pop_density | dbl | inhabitants per km² (census pop / commune area) |
| median_income | dbl | median standard of living (Filosofi; NA pre-2012) |
| csp_*_pct | dbl | CSP shares: agri, indep, cadres, interm, employes, ouvriers, retraites, autres |
| higher_ed_pct, no_diploma_pct | dbl | education shares of non-schooled 15+ |
| census_vintage | int | census millésime used for this row |
| geo_ref_year | int | reference geography for commune harmonization (2022) |

## `tierA_commune_wide` — one row per commune × year × round

Left aggregates + turnout + census (no per-candidate rows):

| column | type | description |
|--------|------|-------------|
| code_commune, year, round | | keys |
| total_left_share | dbl | Σ left votes / exprimes × 100 |
| left_<family>_share | dbl | per-family Left share (e.g. `left_socialiste_share`) |
| inscrits, votants, exprimes, abstention_rate | | turnout |
| pop_density, median_income, csp_*_pct, higher_ed_pct, no_diploma_pct | | census |
| census_vintage, geo_ref_year | | provenance |

## `tierB_bureau_de_vote` — long, bureau-de-vote level (2002–2022)

Same candidate/vote columns as Tier A long, keyed by:

| column | type | description |
|--------|------|-------------|
| bv_id | chr | `code_commune _ code_bv` |
| code_commune | chr | parent commune |
| year, round | | keys |
| voix, share, inscrits, votants, exprimes, abstention_rate | | votes/turnout for the precinct |
| pop, pop_density, median_income, csp_*_pct, higher_ed_pct, no_diploma_pct | | **interpolated** census (dasymetric) |
| bv_area_km2 | dbl | precinct polygon area |
| interp_quality_flag | chr | "ok" / "sparse" (income missing or zero population) |
| census_vintage | int | census/Filosofi vintage interpolated |

## `tierB_bureau_de_vote_wide` — one row per bv × year × round
Left aggregates (`total_left_share`, `left_<family>_share`) + turnout + interpolated
census, keyed by `bv_id, year, round`.

## Lookups (editable inputs)
- `data/lookups/left_classification.csv` — `year, nom, prenom, party, family, is_left, notes`
- `data/lookups/census_vintage_map.csv` — `election_year, census_vintage, income_vintage, income_source, notes`
